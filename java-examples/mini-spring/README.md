# 🛠️ Mini-Spring Modernization

This folder contains the legacy (`before/`) and modernized (`after/`) versions of the **Mini-Spring** application.

Modernization was performed using **Amazon Q Developer**, along with manual effort where required. The goal of this transformation is to demonstrate how legacy applications can be evolved into maintainable, modern architectures with minimal disruption.

---

## 🧭 Project Overview

- **Original Tech Stack**: Java 8 + Spring Framework 4
- **Modern Tech Stack**: Java 21 + Spring Framework 6
- **Key Objective**: Eliminate XML configs, Remove bad practices, Update/Remove/Add dependencies
- **Modernization Tools**: Amazon Q Developer
- **IDE**: Visual Studio Code, IntelliJ IDEA

---

## 📁 Folder Structure

```
mini-spring/
├── before/     # Original legacy implementation
└── after/      # Refactored modern application
```

Each subfolder contains a runnable version of the app and relevant documentation.
