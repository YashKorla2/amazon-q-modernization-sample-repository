# 🛠️ Asp-Net-Mvc5-Architecture Modernization

This folder contains the legacy (`before/`) and modernized (`after/`) versions of the **Asp-Net-Mvc5-Architecture** application.

Modernization was performed using **Amazon Q Developer**, along with manual effort where required. The goal of this transformation is to demonstrate how legacy applications can be evolved into maintainable, modern architectures with minimal disruption.

---

## 🧭 Project Overview

- **Original Tech Stack**: .NET Framework 4.5 + MVC 5
- **Modern Tech Stack**: .NET Core 8.0 + Core MVC
- **Key Objective**: Modernize architecture, Remove bad practices, Update/Remove/Add dependencies
- **Modernization Tools**: Amazon Q Developer
- **IDE**: Visual Studio
- **Web Based Modernization**: Amazon Q Developer Web Experience

---

## 📁 Folder Structure

```
asp-net-mvc5-architecture/
├── before/     # Original legacy implementation
└── after/      # Refactored modern application
```

Each subfolder contains a runnable version of the app and relevant documentation.
